# KAGGLE_SETUP Logs Directory

This directory stores runtime and diagnostics logs during Kaggle Tier 0 worker execution (Bible §24):
- `vllm_stdout.log`: Console and token throughput logs from vLLM cognition server.
- `comfyui.log`: ComfyUI workflow execution and generation logs.
- `harness_execution.log`: HMAC envelope verification and harness evaluation results.
- `gateway_tunnel.log`: Cloudflare tunnel connection and heartbeat logs.
