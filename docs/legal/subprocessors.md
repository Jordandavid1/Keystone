## Authorized Infrastructure Subprocessors
KEYSTONE engages third-party infrastructure providers to support sovereign cloud hosting, asset storage, and payment processing:

1. **Google Cloud Platform (GCP):**
   - **Services:** Cloud Run (container hosting), Cloud SQL (PostgreSQL database), Cloud Storage (encrypted asset binaries), Secret Manager.
   - **Location:** United States.
   - **Compliance:** SOC 1/2/3, ISO/IEC 27001, GDPR.

2. **Stripe, Inc.:**
   - **Services:** Payment processing, credit subscription billing, test-mode webhooks.
   - **Location:** United States.
   - **Compliance:** PCI-DSS Level 1.

3. **Kaggle (Bootstrap Worker Infrastructure):**
   - **Services:** Ephemeral GPU worker instances (Nvidia Tesla T4x2) running pinned open checkpoints under isolated execution envelopes.
   - **Location:** United States.
